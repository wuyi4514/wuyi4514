## Try something I've built

### [Readside](https://github.com/wuyi4514/readside)

**Read another language. Keep the original in view.**

A Chrome extension for bilingual webpage reading, with local translation by default and word or sentence lookup. Built around preserving the page you're already reading.

[Download](https://github.com/wuyi4514/readside/releases/latest) · [Getting started](https://github.com/wuyi4514/readside/blob/main/docs/INSTALL.md) · [Source](https://github.com/wuyi4514/readside)

### [NeoOrg — collaboration prototype](https://github.com/wuyi4514/FishMarket)

An exploration of people and AI teammates working toward a shared goal, with one accountable owner and independent review. This is the open-source prototype I built for the AI Builder Cup competition. I'll continue documenting and sharing the development of the full product on [Douyin](https://v.douyin.com/k87b3ZplP_s/).

[Explore the prototype](https://github.com/wuyi4514/FishMarket) · [Architecture](https://github.com/wuyi4514/FishMarket/blob/main/docs/technical-overview.md)

## How I build

- Start with a specific problem and clear constraints.
- Use AI to build something people can try, then refine the experience.
- Make product decisions, experiments, and lessons part of the work I share.
